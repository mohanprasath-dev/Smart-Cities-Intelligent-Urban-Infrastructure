# UrbanPulse — Smart Cities & Intelligent Urban Infrastructure

> **Intelligent Infrastructure for Tomorrow's Cities**

A competition-ready, AI-assisted website built with **SvelteKit 5 + Tailwind CSS 4** exploring how artificial intelligence, IoT sensor networks, and data-driven analytics can transform urban infrastructure for smarter, safer, more sustainable cities.

**Built by Mohan using AI-assisted development.**

---

## Quick Start

```bash
cd website
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
npm run preview
```

Static output is generated in `website/build/`.

## Website Structure (5 Pages)

| Page | Route | Purpose |
|------|-------|---------|
| **Home** | `/` | Hero, stats, features, how-it-works, testimonials, CTA |
| **About** | `/about` | Mission, values, impact numbers, AI workflow |
| **Smart Infrastructure** | `/infrastructure` | 4 deep-dive solutions: transportation, energy, water, structural health |
| **Urban Analytics** | `/analytics` | 6 analytics modules, data pipeline, case studies |
| **Contact** | `/contact` | Full validated form with toast notifications, FAQ, developer credit |

---

## Tech Stack

- **Framework:** SvelteKit 5 (Svelte 5 with runes)
- **Styling:** Tailwind CSS 4 (CSS-first configuration)
- **Adapter:** `@sveltejs/adapter-static` (deploy anywhere)
- **Language:** TypeScript
- **Fonts:** Inter + Space Grotesk (Google Fonts)
- **Images:** Unsplash (high-quality, relevant stock photography)

---

## Key Features

- **Scroll progress bar** — gradient indicator showing page scroll position
- **IntersectionObserver animations** — fade-up, fade-left, fade-right, scale-in with stagger delays
- **Animated counters** — numbers count up when scrolled into view
- **Mobile-first responsive** — works on all screen sizes
- **Back-to-top button** — appears after scrolling 500px
- **Form validation** — real-time inline validation + toast notification system
- **Reduced motion support** — respects `prefers-reduced-motion` system setting
- **SEO meta tags** — unique title, description, OG tags per page
- **WCAG AA accessibility** — focus-visible rings, aria labels, semantic HTML, alt text
- **Dark gradient hero sections** — with animated glowing orbs and grid overlays
